holton.xyz is the home of Holton LLC and a technology blog. Posts are grouped by year, so everything
from 2026 lives at [/posts/2026.php](/posts/2026.php).

The site is a Laravel + Inertia + Vue app. Posts are plain Markdown files in `resources/posts/`,
named `YYYY-MM-DD-N.md`, with YAML front matter:

```yaml
---
title: 'Hello from holton.xyz'
published: 2026-11-19 09:00:00
tags: [meta, laravel]
---
```

Code blocks, tables and the rest of GitHub-flavored Markdown work as you'd expect:

| Layer    | Choice            |
| -------- | ----------------- |
| Backend  | Laravel 13        |
| Frontend | Inertia 3 + Vue 3 |
| Styling  | Tailwind CSS 4    |

Screenshots and diagrams go in `public/images/YYYY/` and are referenced with normal Markdown.

New posts are created with:

```bash
php artisan post:new "Upgrading to PHP 8.5"
```
